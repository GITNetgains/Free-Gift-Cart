2. Email

Do mein se koi ek chuno. Dono mein email aapke apne address se jaata hai, jaise support@zioncases.com.

Option A: Gmail / Google Workspace

Agar support email Google pe hai.

  1. Us Google account mein login karo jisse email bhejna hai.
  2. Google Account → Security → 2-Step Verification on karo.
  3. Wahin App passwords kholo → naam likho "Zion Help Desk" → Create.
  4. 16 letters ka password dikhega. Use copy karke safe rakho.
LimitGmail se din ke lagbhag 500 emails (Workspace mein 2,000). Normal password nahi chalega, sirf App Password.

Option B: Brevo

Free plan: 300 emails/din. Emails spam mein jaane ke chances kam.

  1. brevo.com pe free account banao.
  2. Senders, Domains & Dedicated IPs mein support email add karke verify karo.
  3. Domain zioncases.com authenticate karo: Brevo jo DNS records (DKIM, DMARC) bataye, unhe domain ke DNS mein daalo.
  4. SMTP & API → SMTP tab se SMTP login aur ek naya SMTP key banao.

3. WhatsApp

WhatsApp ke 2 zaroori rule(1) Customer ko pehla message, ya 24 ghante ki chuppi ke baad ka message, sirf Meta se approve hue template se ja sakta hai. (2) Customer ne pichhle 24 ghante mein message kiya ho, tabhi aap normal text reply bhej sakte ho. Isliye ek template chahiye jaise: "Hi {{1}}, we've replied to your request #{{2}}. Tap to view: {{3}}".

Option A: Meta WhatsApp Cloud API (direct)

Sabse sasta, sirf Meta ka per-message charge. Setup thoda lamba.

  1. business.facebook.com pe Meta Business account banao, aur Business verification karo (GST / company documents).
  2. Ek naya phone number lo jo kisi WhatsApp ya WhatsApp Business app pe active na ho.
  3. developers.facebook.com → Create App → Business → WhatsApp product add karo → number jodo.
  4. Business Settings → System users → ek system user banao → permanent token banao, permission whatsapp_business_messaging aur whatsapp_business_management ke saath.
  5. WhatsApp Manager → Message templates mein upar jaisa template banao aur approve karwao (category: Utility).
  6. Payment method add karo (Meta per conversation/message charge karta hai).

Option B: Partner (Interakt / AiSensy / Twilio)

Setup aasaan, unki team madad karti hai. Mahine ki fees + message charge.

  1. Partner ki site pe account banao aur unka WhatsApp onboarding pura karo (woh Meta verification aur number mein madad karte hain).
  2. Unke dashboard mein template banao aur approve karwao.
  3. Unke dashboard se API key lo.
Agar pehle se koi partner use ho raha haiToh wahi le lo. Developer usi ke hisaab se integration banayega.

4. SMS

SMS chhota hota hai, isliye isme reply ka chhota hissa aur request page ka link jaata hai. Customer jawab request page se deta hai.

India ke customers: MSG91

  1. DLT registration (sarkari rule, zaroori): Jio / Airtel / Vi / BSNL ke kisi DLT portal pe company register karo (PAN, GST, letter of authorisation).
  2. DLT pe Sender ID / Header approve karwao (6 letters, jaise ZIONCS).
  3. DLT pe SMS template approve karwao, jaise: "Hi {#var#}, we replied to your request #{#var#}. View: {#var#} - Zion Cases".
  4. msg91.com pe account banao, DLT details jodo, credit daalo.
  5. MSG91 → API se Auth Key lo, aur template ka Template ID note karo.

Bahar ke customers: Twilio

  1. twilio.com pe account banao aur verify karo.
  2. Ek phone number kharido jo SMS bhej sake (US/UK jaisa).
  3. Console se Account SID aur Auth Token lo.
  4. US numbers ke liye A2P 10DLC registration lagta hai (Twilio console batata hai).

5. Details kaise deni hain (safety)

Passwords aur keys WhatsApp, email ya chat mein mat bhejoJiske paas key hogi, woh aapke account se messages bhej sakta hai aur kharcha karwa sakta hai.
  1. Sabse sahi: developer Help Desk mein Settings → Channels page banayega. Aap khud wahan key paste karke Connect dabaoge. Key turant check hogi aur sirf server pe safe rahegi; browser ko kabhi wapas nahi bheji jaati.
  2. Email ke liye abhi: server ki .env file mein khud daal sakte ho (developer steps dega), ya password manager (Bitwarden / 1Password) ke share link se do.
  3. Kaam hone ke baad koi key leak hone ka shak ho, toh provider ke dashboard se naya key bana ke purana band (revoke) kar do.

6. Decide karna hai

  • Email: Gmail / Google Workspace ya Brevo? Kaunse address se email jaaye?
  • WhatsApp: Meta direct ya partner (Interakt / AiSensy / Twilio)? Pehle se koi WhatsApp Business account hai? Kaunsa number use hoga?
  • SMS: customers zyada India ke hain (MSG91) ya bahar ke (Twilio), ya dono?
  • Customer ke jawab: WhatsApp pe customer jawab de toh woh seedha usi ticket mein aaye? (Recommended: haan.)
  • Phone number: form mein phone zaroori karna hai?
