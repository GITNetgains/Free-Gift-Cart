1. Ek nazar mein: kya bana hai

2. Pehli baar setup (har store pe)

Yeh kaam har store pe alag karna hai, kyunki theme aur settings har store ki apni hoti hain.

  1. Help Desk form page pe lagao. Online Store → Themes → Customize → apna Contact/Support page kholo → Add section/block → Help Desk form → Save. Block settings mein Wholesale aur Affiliate signup page ke URL daal do.
  2. Team aur signature. Har staff member (jiske paas Shopify admin access hai) ek baar Apps → Zion App → Help Desk khol le: woh apne aap Settings → Team → Shopify staff mein aa jaata hai aur tickets usko assign ho sakte hain. Kisi ko assign list se hatana ho toh uska switch band karo. Jinke paas Shopify login nahi (jaise warehouse team), unke naam Other names mein comma laga ke daalo. Phir Settings → Emails mein Reply signature daalo → Save.
  3. Saved replies dekh lo. Settings ke neeche 5 saved replies pehle se hain. Apne hisaab se badlo ya naye jodo.
  4. AI Photo Check: detector key zaroor daalo. Settings → AI photo check → AI detector chuno (Sightengine ya TruthScan) → apni API key daalo → Save AI photo check. Key save karte waqt provider se verify hoti hai. Bina key ke sirf free checks (layer 1-4) chalte hain, aur jo photo woh decide nahi kar paate woh "Can't confirm" reh jaati hai.
  5. Emails (server pe, ek baar). Customer aur team ko email bhejne ke liye server ki .env mein SMTP settings chahiye. Abhi yeh set nahi hain, isliye emails nahi jaate. Section 6 dekho.
  6. Test karo. Storefront pe photo ke saath form bhejo. Admin mein ticket bina refresh kiye aa jaana chahiye, aur photo pe AI check ka badge.

3. Customer ka safar: form aur request page

Form bhejna

  1. Customer topic chunta hai (Order Queries sabse upar). Login customer ka naam, email, phone apne aap bhar jaata hai, aur order number poochha nahi jaata: uske orders ki list aati hai (naye se purane, purane orders bhi), sabse naya order pehle se chuna hota hai, aur order chunte hi uske products dikh jaate hain. Topic ke hisaab se sahi orders upar aate hain (Update order pe jo ship nahi hue, Return/Issue pe jo ship ho chuke); aisa koi na ho toh saare orders dikhte hain. "My order isn't listed" chun ke number khud bhi likh sakta hai.
  2. Login nahi hai toh order number likhna padta hai, aur wahin "Sign in" ka link aata hai.
  3. Topic ke hisaab se fields aati hain: order number, issue, product chunna, photos (5 tak, 10 MB har ek, JPG/PNG/WebP).
  4. Submit karte hi screen pe dikhta hai: "Your request #1007 has been received" aur View your request ka link.
  5. Customer ko confirmation email jaata hai (jab SMTP set ho) jismein ticket number aur private link hota hai.

Request page (customer ka private page)

Link aisa hota hai: https://store-domain/apps/help-desk?ticket=.... Yeh page store ki apni theme ke andar khulta hai (header/footer same), aur mobile pe bhi theek dikhta hai.

  • Progress tracker: Received → Team is on it → Your reply → Resolved. Abhi ka step laal ring se highlight hota hai.
  • Upar ka box batata hai abhi kya ho raha hai (jaise "We've replied: your turn").
  • Conversation chat jaisi dikhti hai: customer ke messages right side (dark), team ke left side "Support team" tag ke saath. Time customer ke apne time zone mein dikhta hai.
  • Right side (mobile pe neeche): "Your request" mein form ki saari details aur "Good to know".
  • Upar status dikhta hai, jaise "We've replied and are waiting for your response".
  • Customer ki original request aur poori conversation (aapke replies, uske jawab).
  • Add a message box sirf tab khulta hai jab aapki team ne reply kiya ho (status "Waiting on customer"). Tab customer text aur 3 tak photos ke saath jawab de sakta hai. Jawab aate hi ticket Open ho jaata hai, team ko email jaata hai, aur box tab tak band ho jaata hai jab tak team phir se reply na kare.
  • Status Open ya In progress pe customer ko dikhta hai: "Our team will reply soon". Resolved pe: "This request is closed", nayi request bhejo.
  • Internal notes aur activity log customer ko kabhi nahi dikhte.

Link kho gaya?

Customer /apps/help-desk?ticket= kholke request number + email daal ke apni request dhoondh sakta hai. 5 galat koshish ke baad 15 minute ka lock lagta hai, taaki koi doosron ki request guess na kar sake.

Signed-in customer

Jo customer login hai, use form ke upar "Your requests" list dikhti hai: uske saare tickets, status ke saath, ek click pe khulte hain.

4. Roz ka kaam: inbox aur ticket

Inbox (Apps → Zion App → Help Desk)

  • Upar ke 4 boxes: Needs attention, Waiting on customer, High priority, Flagged photos. Box pe click karo toh wahi tickets khulte hain. Setup adhoora ho toh upar "Finish setting up" ka banner aata hai (Continue setup). Poore numbers aur setup checklist Overview & setup tab mein hain.
  • Views (tabs): Needs attention · Waiting on customer · Resolved · All tickets, phir Unassigned · High priority · Flagged photos (jinki photo AI/reused nikli). Har tab pe ginti likhi hai.
  • Search: #number, naam, email, order number ya tag se.
  • Filters button dabao toh topic, priority, assignee aur Created (Today / 7 / 30 / 90 din) khulte hain. Lage hue filters chips ban ke dikhte hain, chip ka × dabao toh hat jaata hai. Sort (Last activity / Newest / Oldest) search ke bagal mein.
  • Row mein: New matlab abhi tak kisi ne nahi khola · AI photo / Reused photo matlab photo pe shak hai · laal "No reply yet · 5h" matlab abhi tak pehla jawab nahi gaya.
  • Bulk: checkbox se kai tickets chuno → status, priority ya assignee ek saath badlo, ya Delete.

Ticket kholne pe

  1. Conversation padho. Chat jaisa dikhta hai: customer ke messages left mein (grey), aapki team ke replies right mein (navy), internal notes right mein peele. Customer ki request, photos, replies, notes aur activity log ek hi timeline mein. Pichhli visit ke baad aaye customer messages pe New.
  2. Reply likho. "Reply to customer" chuno. Send via mein chuno reply kahan jaaye: Request page (default: customer ke store wale private page pe chat mein dikhta hai) ya Email (page pe bhi aur customer ke inbox mein bhi). WhatsApp aur SMS abhi "Connect" dikhate hain: account jodne ke baad chalenge. Insert a saved reply se ready jawab daalo (doosra saved reply chunoge toh pehle wala text hat ke naya aa jaata hai). Placeholders jaise {{ customer.first_name }} apne aap bhar jaate hain. Reply as mein apne aap aapka naam hota hai (jo Shopify mein login hai).
  3. Bhejo. Send reply (status apne aap "Waiting on customer") ya Send and resolve.
  4. Internal note sirf team ke liye (peela box), customer ko kabhi nahi dikhta.
  5. Right side: Status, Priority, Assignee, Tags badlo. Tags ke neeche suggestions aate hain: "From this request" (customer ne jo chuna/likha, jaise defective, return, damaged) aur "Your team uses" (store mein sabse zyada lage tags). Chip pe click karo toh tag lag jaata hai. Saath mein customer ki details, recent Shopify orders, purane tickets, emails ka status, aur sabse neeche Delete ticket.

Ticket delete karna

Do tarike: (1) ticket kholke right side mein sabse neeche Delete ticket, (2) list mein checkbox se ek ya kai tickets chun ke Delete. Ek confirm box aata hai: Delete permanently dabane pe ticket, uski poori conversation, notes, photos, photo checks aur emails hamesha ke liye hat jaate hain, aur customer ka request page link band ho jaata hai. Wapas nahi aata, isliye spam ya test tickets ke liye hi use karo; normal kaam ke liye Resolved karo.

Live chat jaisa, dono tarafAdmin: inbox aur khula ticket har ~4 second mein check karte hain. Customer ka naya ticket, message ya photo check ka result aate hi screen apne aap update hoti hai, aur ticket khula ho toh "New message from the customer" ka popup aata hai. Jo reply aap type kar rahe ho woh nahi mitta. Customer ka request page: har ~5 second mein check karta hai. Team ka reply aate hi page reload kiye bina naya message aa jaata hai aur "New message from our team" dikhta hai. Customer ka reply bhi bina reload ke jaata hai. Internal notes customer ke page pe kabhi nahi aate.

5. AI Photo Check

Return/refund ke liye customer jo photo bhejta hai, woh apne aap background mein check hoti hai. Isse customer ko koi deri nahi hoti. 5 layers mein check hota hai, sabse pakke (aur free) saboot se shuru. Pehli 4 layers kuch pakka paa lein toh wahin faisla; kuch na milein toh layer 5, AI detector aapki apni Sightengine/TruthScan key se chalta hai:

CheckKya dekhta haiKharcha
1. Content Credentials (C2PA)OpenAI, Adobe Firefly, Google jaise tools photo ke andar "AI se bani hai" likh dete hain.Free
2. Watermark / signatureStable Diffusion/ComfyUI ki settings, C2PA mein declared invisible watermark, aur Gemini ka chamakta star (✦) kone mein. Yeh WhatsApp forward ke baad bhi pakda jaata hai. (SynthID jaisa pixel watermark offline check nahi ho sakta; use layer 5 pakadta hai.)Free
3. Metadata (EXIF)AI tool ka naam, "ChatGPT Image..." jaisa file name, gpt-image jaisa pixel size, camera ki details.Free
4. Hash / known imagePhoto ka SHA-256 aur perceptual hash: yahi photo (ya thoda badla hua version) pehle kisi aur ticket mein aayi thi? Pehle AI nikli photo ki copy ho toh woh bhi AI.Free
Saath mein: editing ke nishaanPhotoshop/Canva, camera preview match nahi karta, screenshot ya app export.Free
5. AI detector (aakhri layer)Sightengine ya TruthScan ka trained model: "AI 94% · Real 6%" jaisa result. Har us photo pe chalta hai jiska faisla layer 1-4 na kar paayein.Aapki key

Badge ka matlab

Poori report (popup)

Har photo ke neeche rangeen badge hai jisme View report › likha hai. Uspe click karo (ya photo kholke View full report), toh AI photo check report popup khulta hai. Photo checks page pe bhi row pe click karne se ya Full report button se yahi popup khulta hai. Popup mein:

  • Upar result: photo, verdict (jaise "Likely AI-generated"), "kitna sure" ki bar, ek line mein matlab, aur side mein 3 points: kitne strong AI signs, kitne suspicious signs, kitne checks pass hue.
  • What to do (navy box): is result pe aage kya karna hai, jaise customer se nayi photo maango.
  • Checks at a glance: 6 rangeen tiles, har check ka ek. Laal = AI evidence found, peela = Suspicious ya Needs setup, hara = Passed, neela = Info only, grey = Not run.
  • AI detector panel: AI detector ka alag bada box.
    • Detector chala ho toh meter (Real → AI) pe % dikhta hai: 40% se kam = Looks real, 40-69% = Unsure, 70%+ = Likely AI. Saath mein kaunse AI tool (ChatGPT, Midjourney...) se bani hogi.
    • Not connected (peela): detector ki key nahi daali, sirf free checks chale. Connect AI detector button settings kholta hai.
    • Error (laal): key galat hai ya checks khatam ho gaye. Wajah aur fix wahi likha hota hai, saath mein Try the AI detector again button.
    • Not needed: free checks ne pehle hi faisla kar diya. Chaho toh Get a second opinion se detector chala lo.
  • Issues found: har problem alag card mein: laal = AI evidence (pakka saboot), peela = Suspicious (shak). Har card pe likha hai kya mila aur kis check ne pakda ("Found by"). Reused photo ho toh doosre ticket ka link bhi.
  • Every check, step by step: 6 checks ki detail. Click karke dekho woh check kya dekhta hai aur usne kya paaya. Jin checks mein issue ya setup baaki hai woh apne aap khule rehte hain.
  • Photo details: size, format, camera, kab li gayi, software, location data.
  • Neeche buttons: Re-scan photo aur Done.

AI detector chal raha hai ya nahi? (Photo checks page)

Help Desk → Photo checks page pe sabse upar AI detector status box hai:

StatusMatlab aur kya karein
WorkingDetector connected hai aur result de raha hai. Sab theek.
ConnectedKey save hai, abhi tak kisi photo ko detector ki zaroorat nahi padi.
Not connectedKey nahi daali. Connect AI detector dabao aur Sightengine ya TruthScan key daalo. Jo photos ruki hain woh apne aap dobara check hongi.
Needs attentionDetector ka aakhri call fail hua (key galat, checks khatam). Wajah box mein likhi hai. Fix in settings dabao.
OffAI photo check band hai. Turn on dabao.

Neeche teen numbers: kaunsa detector, pichhle 30 din mein kitne detector checks, aur aakhri result kab aaya.

Detector kab chale (Settings → AI photo check)

  • Every photo the free checks can't settle (recommended, default): layer 1-4 faisla na karein toh har photo detector ko jaati hai.
  • Skip clear camera originals: checks bachata hai; jinki camera details poori aur sahi hain, woh detector ko nahi jaatin.
  • Only when I click: kabhi apne aap nahi, sirf button dabane pe.

Ek hi photo pe dobara paisa nahi lagta (purana result reuse hota hai). Key save karte waqt provider se verify hoti hai. Jo photos bina key ke scan hui thi, unhe key daalte hi detector apne aap dobara check karta hai.

Yeh saboot hai, faisla nahiWhatsApp jaise apps photo ka metadata hata dete hain, isliye metadata na hona customer ke khilaaf nahi gina jaata. Badge ko ishaara samjho: shak ho toh customer se aur photo ya video maango, seedha mana mat karo.

Queue aur retry

Har email pehle database mein save hota hai, phir bheja jaata hai. Fail ho jaaye toh 1 minute, phir 5 minute baad dobara try. 3 baar fail hone pe "Email failed" dikhta hai aur ticket pe Retry button aata hai. Ticket ke right side mein Emails section mein har email ka status dikhta hai.

Abhi emails band hainServer pe SMTP settings nahi hain, isliye abhi koi email nahi jaata. Tickets aur request page phir bhi poori tarah chalte hain, customer reply request page pe dekh sakta hai. Emails chalu karne ke liye server ki /var/www/zion-app/.env mein yeh daalo, phir app restart karo (Section 8): 
SMTP_HOST=smtp.gmail.com        # ya aapka mail server
SMTP_PORT=587                   # 465 ho toh SSL apne aap
SMTP_USER=support@yourstore.com
SMTP_PASS=app-password-yahan
SMTP_FROM=support@yourstore.com # optional
Gmail ho toh normal password nahi, App Password lagega. Settings mein Send test email se check karo.

7. Security aur limits

  • Har store ka data alag: server Shopify ke signed request se store pehchanta hai. Koi URL badal ke doosre store ka data nahi dekh sakta.
  • Request page ka link secret hai: 48 character ka random token. Isliye customer ko link share na karne ko kaho.
  • Internal notes aur activity log customer ko kabhi nahi bheje jaate.
  • Spam se bachav: chhupa "honeypot" field, aur har visitor ki limit:
KaamLimit (har visitor)
Naya ticket5 per minute
Reply bhejna10 per minute
Galat request lookup5 galti → 15 minute lock
  • Photos: sirf asli JPG/PNG/WebP, 10 MB tak har ek. Naam badal ke koi aur file upload nahi ho sakti, andar ke bytes check hote hain.
  • Privacy (GDPR) webhooks: customer Shopify se apna data delete karwaye toh uske saare tickets apne aap delete ho jaate hain. Store app hataye toh 48 ghante baad Shopify ke kehne pe us store ka saara Help Desk data saaf ho jaata hai.
  • AI detector keys sirf server pe rehti hain, browser ko kabhi nahi bheji jaatin. (Abhi database mein bina encryption ke save hoti hain.)

Limits server ki memory mein hain: server restart pe reset ho jaati hain. Abhi ek hi server hai, toh yeh theek hai.

Naya version deploy karna

A. Apne computer pe (project folder mein):

pnpm test                      # sab tests pass hone chahiye
git push origin main           # code GitHub pe
npx shopify app deploy --allow-updates --message "kya badla"   # theme widget/blocks

B. Server pe (ssh root@2.25.226.33):

TS=$(date +%Y%m%d-%H%M%S); mkdir -p /root/backups
cp -a /var/www/zion-app/prisma/dev.sqlite /root/backups/zion-app-dev-$TS.sqlite   # DB backup
cd /var/www/zion-app
git fetch origin && git reset --hard origin/main
CI=true pnpm install --frozen-lockfile
npx prisma migrate deploy      # database badlav
npx prisma generate            # Prisma client naye schema se (zaroori!)
rm -rf build.prev && cp -a build build.prev   # purana build sambhal ke
pnpm run build
pm2 restart zion-app --update-env
pm2 logs zion-app --lines 30 --nostream       # error toh nahi?

Gadbad ho toh wapas (rollback)

cd /var/www/zion-app
rm -rf build && cp -a build.prev build       # purana build wapas
pm2 restart zion-app
# database bhi wapas chahiye toh (pehle app band karo):
pm2 stop zion-app
cp /root/backups/zion-app-dev-<TIMESTAMP>.sqlite prisma/dev.sqlite
pm2 start zion-app

10. Jaldi yaad rakhne wali baatein

Roz

  • Inbox ka Needs attention view khaali karo.
  • Laal "No reply yet" wale tickets pehle.
  • AI photo / Reused photo wale tickets dhyan se dekho.
  • Reply ke liye saved replies use karo.

Har hafte

  • Average first response time dekho.

Kabhi mat bhoolo

  • Internal note customer ko nahi dikhta, reply dikhta hai. Bhejne se pehle tab dekh lo.
  • Photo badge saboot hai, faisla nahi.
  • Server pe deploy se pehle database backup.
  • Dono stores ek hi server pe hain: server ka badlav dono pe lagta hai.

Abhi baaki

  • Dono stores pe AI detector key (Sightengine ya TruthScan).
  • Server pe SMTP settings (emails ke liye).
