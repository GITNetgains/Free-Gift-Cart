2. Pehli baar setup (har store pe)

Yeh kaam har store pe alag karna hai, kyunki theme aur settings har store ki apni hoti hain.

  1. Help Desk form page pe lagao. Online Store → Themes → Customize → apna Contact/Support page kholo → Add section/block → Help Desk form → Save. Block settings mein Wholesale aur Affiliate signup page ke URL daal do.
  2. Chat widget on karo. Online Store → Themes → Customize → left side mein App embeds → Help Desk chat on → Save. Yahan title, colour aur position (right/left) bhi set hoti hai.
  3. Chatbot ki answers bharo. Apps → Zion App → Help Desk → Chatbot. Shuru mein 6 answers pehle se hain. Apni store policies add karo: shipping kitne din, return kitne din mein, payment options, COD, store timing.
  4. Team aur signature. Help Desk → Settings → Team members mein naam (jaise "Priya, Rahul") aur Reply signature daalo → Save.
  5. Saved replies dekh lo. Settings ke neeche 5 saved replies pehle se hain. Apne hisaab se badlo ya naye jodo.
  6. AI Photo Check (optional key). Settings → AI photo check. Free checks bina kisi key ke chalte hain. Zyada pakka result chahiye toh Sightengine (2,000 free checks/mahina) ya TruthScan ki API key daalo.
  7. Emails (server pe, ek baar). Customer aur team ko email bhejne ke liye server ki .env mein SMTP settings chahiye. Abhi yeh set nahi hain, isliye emails nahi jaate. Section 8 dekho.
  8. Test karo. Storefront pe form bhejo aur chat mein "Talk to our team" try karo. Admin mein dono tickets dikhne chahiye.
Dhyan doChat widget app embed on kiye bina storefront pe nahi dikhega, chahe app mein chat on ho. Aur agar Chatbot page pe "Show the chat widget on my store" off hai, toh embed on hone ke bawajood widget chhupa rahega.

3. Customer ka safar: form aur request page

Form bhejna

  1. Customer topic chunta hai (Order Queries sabse upar). Signed-in customer ka naam, email, phone apne aap bhar jaata hai aur uske recent orders list mein aa jaate hain.
  2. Topic ke hisaab se fields aati hain: order number, issue, product chunna, photos (5 tak, 5 MB har ek, JPG/PNG/WebP).
  3. Submit karte hi screen pe dikhta hai: "Your request #1007 has been received" aur View your request ka link.
  4. Customer ko confirmation email jaata hai (jab SMTP set ho) jismein ticket number aur private link hota hai.

Request page (customer ka private page)

Link aisa hota hai: https://store-domain/apps/help-desk?ticket=.... Yeh page store ki apni theme ke andar khulta hai (header/footer same).

  • Upar status dikhta hai, jaise "We've replied and are waiting for your response".
  • Customer ki original request aur poori conversation (aapke replies, uske jawab).
  • Add a message box sirf tab khulta hai jab aapki team ne reply kiya ho (status "Waiting on customer"). Tab customer text aur 3 tak photos ke saath jawab de sakta hai. Jawab aate hi ticket Open ho jaata hai, team ko email jaata hai, aur box tab tak band ho jaata hai jab tak team phir se reply na kare.
  • Status Open ya In progress pe customer ko dikhta hai: "Our team will reply soon". Resolved pe: "This request is closed", nayi request bhejo.
  • Internal notes aur activity log customer ko kabhi nahi dikhte.

Link kho gaya?

Customer /apps/help-desk?ticket= kholke request number + email daal ke apni request dhoondh sakta hai. 5 galat koshish ke baad 15 minute ka lock lagta hai, taaki koi doosron ki request guess na kar sake.

Signed-in customer

Jo customer login hai, use form ke upar "Your requests" list dikhti hai: uske saare tickets, status ke saath, ek click pe khulte hain.

5. Roz ka kaam: inbox aur ticket

Inbox (Apps → Zion App → Help Desk)

  • Upar ke numbers: Needs attention (kitne kaam baaki), High priority, average first response time (30 din), Resolved (7 din), aur chatbot ne kitne % sawal khud solve kiye.
  • Views: Needs attention · Unassigned · High priority · Waiting on customer · Resolved · Flagged photos (jinki photo AI/reused nikli) · All tickets.
  • Search: #number, naam, email, order number ya tag se.
  • Filters: topic (Live chat bhi), priority, assignee, Created (Today / 7 / 30 / 90 din), sort (Last activity / Newest / Oldest).
  • Row mein: New matlab abhi tak kisi ne nahi khola · chat icon matlab live chat se aaya · AI photo / Reused photo matlab photo pe shak hai · laal "No reply yet · 5h" matlab abhi tak pehla jawab nahi gaya.
  • Bulk: checkbox se kai tickets chuno → status, priority ya assignee ek saath badlo, ya Delete.

Ticket kholne pe

  1. Conversation padho. Customer ki request, photos, bot transcript (chat ho toh), replies, notes aur activity log ek hi timeline mein. Pichhli visit ke baad aaye customer messages pe New.
  2. Reply likho. "Reply to customer" chuno. Insert a saved reply se ready jawab daalo: {{ customer.first_name }}, {{ order.number }} jaise placeholders apne aap bhar jaate hain. Reply as mein apna naam chuno.
  3. Bhejo. Send reply (status apne aap "Waiting on customer") ya Send and resolve.
  4. Internal note sirf team ke liye (peela box), customer ko kabhi nahi dikhta.
  5. Right side: Status, Priority, Assignee, Tags badlo. Customer ki details, uske recent Shopify orders (payment/fulfillment ke saath), uske purane tickets, aur saare emails ka status.

Ticket delete karna

Teen tarike: (1) list mein har ticket ki row ke aakhir mein laal 🗑 button, (2) ticket kholke right side mein Delete ticket section, (3) list mein checkbox se kai tickets chun ke Delete. Ek confirm box aata hai: Delete permanently dabane pe ticket, uski poori conversation, notes, photos, photo checks aur emails hamesha ke liye hat jaate hain, aur customer ka request page link band ho jaata hai. Wapas nahi aata, isliye spam ya test tickets ke liye hi use karo; normal kaam ke liye Resolved karo.

Page apne aap refresh hota haiTicket page har 15 second mein naya data laata hai, taaki chat ke naye messages bina reload dikhein. Jo reply aap type kar rahe ho woh mitta nahi.

6. Chatbot: FAQ aur order status

Bot answer kaise chunta hai

Yeh AI nahi hai, rule-based hai, isliye galat jawab bana ke nahi deta. Customer ke sawal ke shabd har FAQ ke question aur "Other ways customers ask" (keywords) se milaye jaate hain:

  • Jo shabd sirf ek-do FAQ mein hai (jaise "refund"), uska wazan zyada. Jo har jagah hai (jaise "order"), uska kam.
  • Keywords mein likha poora phrase exact mil jaaye (jaise "arrived damaged"), toh bonus milta hai.
  • Do answers lagbhag barabar score karein, ya score bahut kam ho, toh bot jawab nahi deta aur team ka option dikhata hai.

Achha FAQ kaise likhein

FieldExample
Customer questionHow long does shipping take?
Other ways customers askdelivery time, when will it arrive, shipping days, kitne din mein aayega, dispatch time
AnswerOrders ship within 1-2 business days. Delivery usually takes 3-5 days within India.
TipsKeywords mein woh shabd likho jo customer sach mein likhte hain, Hinglish bhi chalega. Ek FAQ mein ek hi topic rakho. Save karne ke baad neeche Try the chatbot box mein sawal daal ke turant check karo.

Order status ke liye

  • Customer order number + order wali email likhe → asli status aur tracking. 5 baar galat order/email pe 15 minute lock.
  • Sirf order number (email nahi) → bot email maangta hai.
  • Signed-in customer → bina email ke uske apne orders.

Chatbot page ke numbers

Questions asked (30 din) · Answered automatically % · Order status lookups · Chats sent to your team (jo ticket bane).

7. AI Photo Check

Return/refund ke liye customer jo photo bhejta hai, woh apne aap background mein check hoti hai. Isse customer ko koi deri nahi hoti. Kai layers mein check hota hai, sabse pakke saboot se shuru:

CheckKya dekhta haiKharcha
Content Credentials (C2PA)OpenAI, Adobe Firefly, Google jaise tools photo ke andar "AI se bani hai" likh dete hain.Free
Watermark / signatureStable Diffusion/ComfyUI ki settings, aur Gemini ka chamakta star (✦) kone mein. Yeh WhatsApp forward ke baad bhi pakda jaata hai.Free
Metadata (EXIF)AI tool ka naam, "ChatGPT Image..." jaisa file name, gpt-image jaisa pixel size, camera ki details.Free
DuplicateYahi photo (ya thoda badla hua version) pehle kisi aur ticket mein aayi thi?Free
Editing ke nishaanPhotoshop/Canva, camera preview match nahi karta, screenshot ya app export.Free
AI detector (optional)Sightengine ya TruthScan ka trained model. Tabhi chalta hai jab upar wale checks faisla na kar paayein.Aapki key

Badge ka matlab

BadgeMatlab aur kya karein
Likely AI-generatedPakka saboot mila (credentials, watermark, AI tool ka naam) ya detector 70%+ bola. Customer se asli photo/video maango.
Reused photoYahi photo pehle kisi aur ticket pe aayi thi. Panel mein us ticket ka link hai, dono dekho.
Can't confirmNa pakka asli, na pakka AI (metadata hata hua, detector key nahi, ya score beech mein). Zaroorat ho toh aur photo maango.
Likely genuineCamera ki asli details theek hain, ya detector ne kam score diya.
Couldn't check / Scan incompleteRe-scan dabao.

Photo pe click karo → Photo check panel: verdict, confidence %, har check ne kya paaya, camera details, aur buttons Re-scan / Check with AI detector.

Detector kab chale (Settings → AI photo check)

  • Only when a photo looks suspicious (recommended): asli camera photo pe paisa nahi lagta, baaki pe chalta hai.
  • Every photo the free checks can't settle: sabse thorough, sabse zyada checks use.
  • Only when I click: kabhi apne aap nahi, sirf button dabane pe.

Ek hi photo pe dobara paisa nahi lagta (purana result reuse hota hai). Key save karte waqt provider se verify hoti hai. Jo photos bina key ke scan hui thi, unhe key daalte hi detector apne aap dobara check karta hai.

Yeh saboot hai, faisla nahiWhatsApp jaise apps photo ka metadata hata dete hain, isliye metadata na hona customer ke khilaaf nahi gina jaata. Badge ko ishaara samjho: shak ho toh customer se aur photo ya video maango, seedha mana mat karo.

Queue aur retry

Har email pehle database mein save hota hai, phir bheja jaata hai. Fail ho jaaye toh 1 minute, phir 5 minute baad dobara try. 3 baar fail hone pe "Email failed" dikhta hai aur ticket pe Retry button aata hai. Ticket ke right side mein Emails section mein har email ka status dikhta hai.

Abhi emails band hainServer pe SMTP settings nahi hain, isliye abhi koi email nahi jaata. Tickets, chat aur request page phir bhi poori tarah chalte hain, customer reply request page/chat pe dekh sakta hai. Emails chalu karne ke liye server ki /var/www/zion-app/.env mein yeh daalo, phir app restart karo (Section 10): 
SMTP_HOST=smtp.gmail.com        # ya aapka mail server
SMTP_PORT=587                   # 465 ho toh SSL apne aap
SMTP_USER=support@yourstore.com
SMTP_PASS=app-password-yahan
SMTP_FROM=support@yourstore.com # optional
Gmail ho toh normal password nahi, App Password lagega. Settings mein Send test email se check karo.

9. Security aur limits

  • Har store ka data alag: server Shopify ke signed request se store pehchanta hai. Koi URL badal ke doosre store ka data nahi dekh sakta.
  • Request page ka link secret hai: 48 character ka random token. Isliye customer ko link share na karne ko kaho.
  • Internal notes aur activity log customer ko kabhi nahi bheje jaate.
  • Spam se bachav: chhupa "honeypot" field, aur har visitor ki limit:
KaamLimit (har visitor)
Bot se sawal20 per minute
Naya ticket / chat shuru5 per minute
Reply bhejna10 per minute
Chat refresh30 per minute
Galat order/request lookup5 galti → 15 minute lock
  • Photos: sirf asli JPG/PNG/WebP. Naam badal ke koi aur file upload nahi ho sakti, andar ke bytes check hote hain.
  • Privacy (GDPR) webhooks: customer Shopify se apna data delete karwaye toh uske saare tickets apne aap delete ho jaate hain. Store app hataye toh 48 ghante baad Shopify ke kehne pe us store ka saara Help Desk data saaf ho jaata hai.
  • AI detector keys sirf server pe rehti hain, browser ko kabhi nahi bheji jaatin. (Abhi database mein bina encryption ke save hoti hain.)

Limits server ki memory mein hain: server restart pe reset ho jaati hain. Abhi ek hi server hai, toh yeh theek hai.

Naya version deploy karna

A. Apne computer pe (project folder mein):

pnpm test                      # sab tests pass hone chahiye
git push origin main           # code GitHub pe
npx shopify app deploy --allow-updates --message "kya badla"   # theme widget/blocks

B. Server pe (ssh root@2.25.226.33):

TS=$(date +%Y%m%d-%H%M%S); mkdir -p /root/backups
cp -a /var/www/zion-app/prisma/dev.sqlite /root/backups/zion-app-dev-$TS.sqlite   # DB backup
cd /var/www/zion-app
git fetch origin && git reset --hard origin/main
CI=true pnpm install --frozen-lockfile
npx prisma migrate deploy      # database badlav
rm -rf build.prev && cp -a build build.prev   # purana build sambhal ke
pnpm run build
pm2 restart zion-app --update-env
pm2 logs zion-app --lines 30 --nostream       # error toh nahi?

Gadbad ho toh wapas (rollback)

cd /var/www/zion-app
rm -rf build && cp -a build.prev build       # purana build wapas
pm2 restart zion-app
# database bhi wapas chahiye toh (pehle app band karo):
pm2 stop zion-app
cp /root/backups/zion-app-dev-<TIMESTAMP>.sqlite prisma/dev.sqlite
pm2 start zion-app

12. Jaldi yaad rakhne wali baatein

Roz

  • Inbox ka Needs attention view khaali karo.
  • Laal "No reply yet" wale tickets pehle.
  • AI photo / Reused photo wale tickets dhyan se dekho.
  • Reply ke liye saved replies use karo.

Har hafte

  • Chatbot page → bot ke "couldn't answer" sawalon ke answers jodo.
  • Average first response time dekho.

Kabhi mat bhoolo

  • Internal note customer ko nahi dikhta, reply dikhta hai. Bhejne se pehle tab dekh lo.
  • Photo badge saboot hai, faisla nahi.
  • Server pe deploy se pehle database backup.
  • Dono stores ek hi server pe hain: server ka badlav dono pe lagta hai.

Abhi baaki

  • Dono stores pe "Help Desk chat" app embed on karna.
  • Server pe SMTP settings (emails ke liye).
  • Optional: AI detector key.
